# NBA 2K12 Showcase Reconstruction

Unity 6 basketball-game development project. This repository is intended to integrate the open-source NeuralCourt 5-on-5 basketball simulation as a Git submodule and build project-owned presentation and gameplay improvements on top.

## Honest status

This is a reconstruction project, not a finished AAA game or an NBA 2K12 asset dump. NeuralCourt is a research prototype with full-court 5-on-5 simulation, a synthetic skinned athlete, court assets, team appearance profiles, ball possession, passes, shots, and motion inference. The synthetic athlete is not an NBA player likeness. Authentic NBA 2K12 faces, uniforms, logos, and animations have not yet been imported.

## Planned setup

The upstream project is https://github.com/henry753951/neuralcourt-basketball. Open it in Unity 6 using the editor version specified in its README, then open Assets/Scenes/BasketballDemo.unity and enter Play Mode.

## Quality priorities

1. Establish a reproducible Unity project and a verified working 5-on-5 baseline.
2. Improve broadcast camera, lighting, court presentation, crowd composition, and player proportions.
3. Add original or properly licensed uniform designs, materials, team data, and rosters.
4. Import game assets only when their format is verified and the user is authorized to use them.
5. Validate movement, ball physics, passing, shooting, collisions, animations, and performance in Play Mode.

Do not claim that a feature or visual improvement is complete until the resulting Unity scene has been inspected and tested.
